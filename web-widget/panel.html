▶How the doors workreference

Three tiers, each including the ones below it:

  • Admin — always exists. Opens this panel, the keys and the test buttons; also opens the phone. Set under Access below.
  • Guest — an optional code you hand out that opens the phone. No username; expires per device if you set a clock; the card offers a lock button to forget it early.
  • Open — no code: anyone who can load the page can call, inside the usage caps.

What stands behind them: passwords are stored as PBKDF2 hashes, never plaintext; wrong guesses are rate-limited fail2ban-style — 5 wrong tries puts the address in a 5-minute cooldown, and a second round of 5 bans it until the app restarts (a restart clears bans, and CALLIN_ADMIN_KEY in the environment is the recovery override); API keys are write-only — the panel shows last-four, never the key; join tokens are signed and short-lived, minted per call; each caller's tier rides inside the signed token, so a caller cannot raise their own; and the station tools a caller can reach go through a hard allowlist — the destructive ones are never on the line at any setting.

▶Usage controls

Every call costs model time and airtime, and one open tab could dial in a loop. Set any to 0 to turn it off. Callers see a friendly “lines are busy”, never an error code.

▶Station awareness

What rides in the DJ's prompt before the call — each item costs time-to-first-token on every turn, not just the first.

  • Always known, no dial: the persona's own DJ card, the current show's write-up and episode angle (guests and handoffs included on programme shows), the track playing right now, and the station's name.
  • Fetched live, never preloaded: the music library (searched on demand, so it always reflects what you actually have) — and the tools look things up for themselves when invoked, which is why a caller with the takeover permission can name another show even while “Know the rest of the line-up” is off: that switch only shapes the prompt.
