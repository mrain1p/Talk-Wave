Admin — this panel

Opens the settings, the keys and the test buttons. Whoever has it can spend your API budget.

Locked out? Set CALLIN_ADMIN_KEY in the environment as a recovery override; restarting clears IP bans.

Guest — the phone

A code you hand out. No username. It must differ from the admin password — a code that also opens this panel defeats the point of having two.

▶Usage controls

Every call costs model time and airtime, and one open tab could dial in a loop. Set any to 0 to turn it off. Callers see a friendly “lines are busy”, never an error code.

▶Turn-taking

The single biggest lever on whether a call feels like a phone call or a kiosk — and the one most worth leaving alone until a real call says otherwise. 0 on either delay keeps the SDK's own tuned default; it does not mean “no wait”.
